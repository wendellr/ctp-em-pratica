# Validação institucional

Estado: **não validado; simulação pedagógica**.

Solicitar material vigente que esclareça:

1. Quando o caso exige formalização no SEI e quando basta outro registro institucional autorizado.
2. Qual procedimento se aplica, a qual campus/unidade e em qual versão do SEI.
3. Quais documentos e informações são necessários.
4. Quem define destinatários, acesso e compartilhamento.
5. Quais revisões, assinaturas e encaminhamentos são exigidos.
6. Como acompanhar o retorno.

Registrar, antes de alterar o estado: fonte, versão/data, abrangência, responsável pela validação, data e trechos efetivamente aprovados. Não anexar dados reais de atendimentos para explicar o fluxo.

A aprovação de um roteiro pela equipe do produto não equivale a validação institucional.
